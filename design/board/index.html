The proposed implementation boundary

One identity.
Existing tools.
A few missing entry points.

Neutral Slate is the selected visual identity, with public tokens and a generated Kitty fragment. Component implementations stay independently owned, and desktop adoption remains separate.

  • Retain Niri, Kanshi, SDDM, Gtklock, SwayNC, Rofi, and the supporting native applications.
  • Unify font/cursor ownership and the owned shell palette, spacing, focus, and feedback.
  • Make Network, Bluetooth and Audio discoverable; add one small Session picker.
  • Preserve current power, authentication, provider, fleet and hardware-trial boundaries.
