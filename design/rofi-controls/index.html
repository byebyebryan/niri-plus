The familiar Plus interface

  • Up/Down selects a row.
  • Tab/Shift+Tab cycles named actions.
  • Enter accepts the visible action.
  • Back restores the landing filter and selection.

Current-state green frames, blue selection, the compact action strip and warm Neutral Slate surfaces stay within the Plus picker.

Three focused utilities, each on its own page.

01 / Network

Warn before open Wi-Fi

Every open-network Connect action shows a Cancel-first warning naming the network and interface. Continuing rechecks that same target’s security and revision. New profiles then offer persistence choices; saved open profiles proceed to activation. The global Wi-Fi switch names affected interfaces and connections; Ethernet remains outside its scope.

02 / Audio

Adjust without losing the target

Set an output or input default, then use a focused Adjust page for repeatable ±5% and mute actions. Changes update inline. Volume adjustments never unmute a microphone.

03 / Bluetooth

Pair, then choose trust

Pair a discovered device after a Cancel-first preflight that names its address and adapter. PIN/passkey prompts, matching-code confirmation and keyboard display are temporary and device-scoped. Trust is a separate confirmed action after pairing. Ten behavioral checks passed against a synthetic BlueZ service through GIO methods and Agent1; physical-device proof remains pending.

Keep the desktop easy to reason about.

SwayNC shows status. Rofi performs short actions. NetworkManager, the audio service and BlueZ keep control of devices. Advanced settings hands off to the installed native editor or recovery tool. Session and Clipboard retain their own helpers.

Close menu, Cancel connection and Stop waiting

Close menu dismisses the picker. Network’s separate Cancel connection targets its owned activation and does not restore an earlier link. Bluetooth’s Stop waiting ends this client’s observation; the native connection request may still finish. The web sample changes no real service.
