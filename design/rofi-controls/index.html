01 / Network

Connect with confidence

Saved and new personal Wi-Fi, readable progress, guarded disconnect, credentials and cancellation. Prove the Rofi and native credential lifecycles first.

02 / Audio

Pick what you hear

Output/input, default device, volume and mute. Keep per-app mixing and profile changes in Pavucontrol. Default changes do not silently move existing streams.

03 / Bluetooth

Reconnect, then pair

Paired devices and power first. Add bounded discovery, pairing and passkey confirmation after that. Trust is an explicit choice.

Keep the desktop easy to reason about.

SwayNC shows status. Rofi performs short actions. NetworkManager, BlueZ and the existing audio stack keep control of devices. Session and Clipboard retain their tested behavior.

Close menu versus cancel connection

Before submission, Escape means no action. After NetworkManager accepts a connection, closing the menu leaves that native request running. “Cancel connection” is a separate targeted action. It must never disconnect a replacement connection started elsewhere. It also does not promise to restore the previous network.
