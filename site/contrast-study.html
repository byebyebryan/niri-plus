02 / Terminal · refined proposal

Keep black.
Separate normal and bright.

All three backgrounds are pure black. Compare the original colors, a balanced middle, and the vivid reference. The paired text uses identical font size and weight.

The earlier “Black background only” used the original muted ANSI colors, not the crisper desktop palette. All options here are sixteen-color ANSI palettes; “Vivid” names only the more saturated reference.

Terminal view
Sample type size
@@TERMINALS@@

Illustrated shell, diff, and agent output. ANSI 0 (black) is shown as a background swatch; it naturally disappears as foreground text on black. The explicit RGB sample is intentionally identical in all three.

Separation inside each family. The balanced proposal uses deeper normal colors and lighter bright partners. Rose stays rose, sage stays sage, and ordinary text stays warm off-white.

Faint is a separate setting. Each card shows 40% and 70% illustrations side by side. The study does not select a new Kitty faint-text setting.

Applications retain some colors. A TUI can use RGB, extended colors, or its own background. A black Kitty background alone does not force every application to be black.
