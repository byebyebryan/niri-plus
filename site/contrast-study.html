02 / Terminal · color samples

A little closer
to vivid.

Balanced → Balanced+ → Rich → Vivid. Two intermediate samples add more color while keeping the normal/bright pairs distinct. Black, warm foreground, font size, and font weight stay fixed.

The earlier “Black background only” used the original muted ANSI colors, not the crisper desktop palette. All options here are sixteen-color ANSI palettes; “Vivid” names only the more saturated reference.

Terminal view
Sample type size
@@TERMINALS@@

Illustrated shell, diff, and agent output. ANSI 0 (black) is shown as a background swatch; it naturally disappears as foreground text on black. The explicit RGB sample is intentionally identical in all three.

More color, with room between shades. Balanced+ and Rich start 40% and 70% toward Vivid. Normal entries are deepened where needed to preserve separation from their bright partners. The endpoints are unchanged.

Faint is a separate setting. Each card shows 40% and 70% faint-text illustrations side by side. These opacities are independent of the palette blend amounts; no new Kitty faint-text setting is selected.

Applications retain some colors. A TUI can use RGB, extended colors, or its own background. A black Kitty background alone does not force every application to be black.
